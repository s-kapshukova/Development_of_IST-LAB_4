# Development_of_IST-LAB_4
Предложена консольная реализация защиты данных пользовательских папок и файлов, находящихся в папке, а также подпапках путем шифрования на языке С++. Для шифрования использрована библиотека Crypto++ Library.

## Инструкция для установки
Необходимо для запуска этого проекта установить библиотеку Crypto++
В Linux это можно сделать с помощью команд:

```
sudo apt update
sudo apt install libcrypto++-dev libcrypto++-utils libcrypto++-doc
```

После установки можно перейти к сборке и запуску проекта.

## Инструкция по компиляции и запуску
Компиляция и создание объектного файла:

`g++ СryptoManager.cpp -o CryptoManager -lcryptopp`

Запуск

`./CryptoManager`

После запуска появится предложение для выбора дальнейших действий
```
1. Encrypt file  //Зашифровать файл
2. Decrypt file  //Расшифровать файл
3. Encrypt folder  //Зашифровать папку
4. Decrypt folder  //Расшифровать папку
Choice: *сюда вписать цифру*
```
После выбора цифры повяится просьба ввести путь до объекта, который Вы хотите зашифровать (или расшифровать), и пароль, необходимый для шифрования.
Если Вы выбрали зашифровать файл, то пароль нужно будет ввести дважды для подтверждения своих действий, иначе - последняя строчка не отобразится
```
Enter path: /home/lana/tests/hello.txt
Enter password: 
Confirm password: 
```
